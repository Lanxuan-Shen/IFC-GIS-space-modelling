IFC files, IfcOpenShell scripts, and GIS resources supporting the prototype implementation described in Extending IFC for 3D Land and Property Data Management in Underground Infrastructure Projects.

# IFC–GIS Prototype Implementation

This repository contains the IFC files, IfcOpenShell scripts, and GIS files supporting the prototype implementation reported in:

Extending IFC for 3D Land and Property Data Management in Underground Infrastructure Projects.

## Repository contents
models/
├── IFC/
│   ├── Underground_drawing_0619_integrated.ifc/
├── GIS/
│   └── GISmodel_7_12.qgz/
└── scripts/
    └── IFC_Integration.ipynb/


- `IFC/`: IFC models used for the prototype
- `scripts/`: IfcOpenShell processing scripts
- `GIS/`: GIS datasets and project files

## Requirements

- Python [3.13.13]
- IfcOpenShell [0.8.5]
- QGIS [4.0.1]

## Data availability

The files in this repository support the prototype implementation. The remaining data supporting the findings of the study are available from the corresponding author upon reasonable request.
